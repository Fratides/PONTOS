# Points

Aplicação web para organizar pontos de venda, registrar pedidos de reposição e acompanhar valores recebidos. O **Points** centraliza o controle operacional e financeiro em uma interface simples, responsiva e acessível de qualquer dispositivo.

## Funcionalidades

- Cadastro e organização de pontos de venda.
- Catálogo de produtos com preços editáveis.
- Registro de pedidos por ponto, com vários produtos, quantidades, preços e datas.
- Acompanhamento do valor total dos pedidos e dos recebimentos, incluindo pagamentos parciais.
- Resumo consolidado de quantidades e valores.
- Criação de conta e acesso por e-mail, além de login com Google quando habilitado no Supabase.
- Preferência de tema claro ou escuro.
- Persistência de dados por usuário, com políticas de acesso no banco.

## Tecnologias

- React 19
- Vite 7
- Tailwind CSS 4
- Supabase Auth e banco de dados PostgreSQL
- Lucide React

## Pré-requisitos
- Um projeto no [Supabase](https://supabase.com/).
